소개

최종 업데이트: 2026년 8월

이 사이트는 무엇인가요

법안·국정과제 트래커(policywatch.kr)는 대한민국 국회에 발의된 법안이 실제로 법이 되기까지 어떤 단계를 거치는지, 정부가 임기 5년 동안 추진하겠다고 밝힌 국정과제가 지금 어디까지 진행됐는지, 그리고 이미 시행 중인 법에는 어떤 것들이 있는지를 한 자리에서 확인할 수 있도록 만든 개인 프로젝트입니다.

국회나 정부 각 부처 홈페이지를 일일이 찾아다니지 않아도, 지금 우리 사회에 어떤 법과 정책이 오가고 있는지 시민 누구나 쉽게 파악할 수 있게 하는 것을 목표로 합니다.

운영자

이 사이트는 시민 개발자 개인이 비영리 목적으로 만들고 운영하는 프로젝트입니다. 특정 정당이나 단체와 관련이 없으며, 정부 공식 데이터를 있는 그대로 전달하는 것을 원칙으로 합니다.

데이터는 어디서, 어떻게 가져오나요

법안 진행 정보 — 국회 열린국회정보 Open API

국정과제 — 국정기획위원회가 2025년 9월 국무회의에서 확정한 '123대 국정과제' 정부 발표 자료

현행 법령 목록 — 법제처 국가법령정보 공동활용 API

세 데이터 모두 정부가 공식적으로 운영·공개하는 공공데이터입니다. 매일 정해진 시각에 프로그램이 각 기관의 API를 자동으로 호출해 최신 정보를 받아오며, 사람이 수작업으로 글을 작성해 올리는 방식이 아닙니다.

이 사이트가 하지 않는 것

  • 특정 법안이나 정책에 대한 찬반 의견이나 논평을 제공하지 않습니다. 정부 공개 데이터를 정리해서 보여주는 것이 이 사이트의 역할입니다.
  • 국회 Open API는 법안의 진행 단계와 날짜는 제공하지만, 법안의 구체적인 제안 이유나 주요 내용까지는 제공하지 않습니다. 법안의 자세한 내용은 각 법안 상세 페이지의 '국회 원문에서 보기' 링크를 통해 국회 의안정보시스템에서 직접 확인하시길 권해드립니다.
  • 현행법 목록은 검색 편의를 위해 주요 관심 분야 위주로 선별한 것으로, 대한민국 전체 법령(6천여 건)을 빠짐없이 담고 있지는 않습니다.
